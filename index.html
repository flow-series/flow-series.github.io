workerFlow

바탕화면에 자연스럽게 녹아드는 타임라인 기반 스케줄 위젯입니다. Google Calendar 동기화와 직관적인 타임라인으로 오늘 하루의 흐름을 한눈에 파악하세요.

  • Google Calendar 실시간 연동
  • 타임라인 & 월간 일정 뷰 제공
  • Windows Mica 투명 반투명 위젯 UI
  • 서버 저장 없는 로컬 중심의 안전한 데이터 관리

slideFlow

디자이너와 크리에이터를 위한 불필요한 요소 없는 미니멀 이미지 뷰어입니다. 드래그 앤 드롭으로 이미지 및 폴더를 감상하고 완벽하게 몰입할 수 있습니다.

  • 몰입형 전체 화면 시청 모드
  • 폴더 드래그 앤 드롭 탐색 지원
  • 사용자 지정 재생 간격의 슬라이드쇼
  • macOS 및 Windows 크로스 플랫폼 지원

focusFlow

  • 웹 브라우저 기반 무설치 크로스 플랫폼

Design Philosophy

인터페이스는 최소한으로,
몰입과 흐름은 극대화.

Flow Series는 복잡한 기능을 덜어내고 사용자의 업무와 창작 흐름을 방해하지 않는 소프트웨어를 만듭니다.

🔒

100% 로컬 보안 중심

모든 데이터는 오직 사용자의 기기에만 안전하게 저장됩니다. 외부 서버 전송이나 추적 코드 없이, 일정을 포함한 모든 소중한 개인정보를 안전하게 보호합니다.

⚡

언제나 바탕화면에 상주

매번 앱을 켰다 끌 필요가 없습니다. workerFlow의 위젯은 항상 바탕화면에 은은하게 녹아들어 있고, slideFlow는 딜레이 없이 즉시 실행됩니다.

🎨

미니멀 UI & 군더더기 없는 디자인

Windows Mica 투명 효과와 반투명 Glassmorphism UI로 바탕화면과 조화를 이룹니다. 군더더기 없는 레이아웃으로 오직 작업과 이미지에만 집중할 수 있습니다.

🌍

7개 국어 다국어 지원

전 세계 사용자를 위해 한국어, 영어, 일본어, 중국어(간체/번체), 스페인어, 프랑스어를 시스템 언어에 맞춰 기본적으로 지원합니다.

💻

Windows & macOS 최적화 호환성

크로스 플랫폼 환경을 고려하여 각 OS의 네이티브 감성에 맞는 최적화된 경험을 제공합니다. 사용자의 디바이스 환경에 구애받지 않고 언제 어디서나 동일한 흐름을 유지하세요.
