# 🧩 Flow Series (플로우 시리즈)
**다양한 워크플로우를 위한 통합 소프트웨어 스위트**

Flow Series는 단일 애플리케이션에 기능적 한계를 두지 않고, 생산성, 시각화, 복잡한 작업을 하나의 통합된 플랫폼에서 관리할 수 있도록 설계된 웹 서비스 모음입니다. 각 기능은 독립적인 '플로우(Flow)'로 격리되어 있어, 안정성과 유지보수성을 극대화했습니다.

## 🚀 주요 기능 (Feature Modules)

본 프로젝트는 세 가지 핵심 모듈로 구성되어 있으며, 각 모듈은 고유한 목적을 가지고 있습니다.

### 🧠 1. FocusFlow (포커스플로우)
개인 생산성 및 태스크 관리에 특화된 기능 모듈입니다. 몰입도 높은 작업 환경을 제공하며, 할 일 목록, 시간 관리, 집중력 향상 도구 등을 포함합니다.

### 🖼️ 2. SlideFlow (슬라이드플로우)
미니멀리스트 프레젠테이션 및 뷰잉 기능에 집중한 모듈입니다. 간결하고 시각적인 콘텐츠를 효과적으로 전달하는 기능을 제공합니다.

### ⏱️ 3. WorkerFlow (워커플로우)
가장 복잡한 기능을 담당하는 모듈입니다. 스케줄링, 워크플로우 엔진, 자동화된 반복 작업을 처리하는 백엔드 중심의 기능을 제공합니다.

## 🛠️ 기술 아키텍처 및 구조

**기본 구조:**
*   **Foundation**: `index.html`, `privacy.html`, `service.html`과 같은 메인 페이지들이 사이트의 기본적인 진입점과 법적 보일러플레이트(Boilerplate)를 담당합니다.
*   **Shared Resources**: `css/` 및 `js/` 디렉토리가 모든 플로우 간의 일관성을 유지하는 전역 자원(글로벌 스타일, 국제화 로직 등)을 제공합니다.
*   **Downloads**: `downloads/` 디렉토리에는 각 워크플로우가 사용할 수 있는 실행 파일 및 설정 파일이 제공됩니다.

**핵심 로직 처리:**
*   **`js/components.js`**: 페이지 로드(`DOMContentLoaded`) 시 실행되어, 글로벌 UI 요소(Header, Footer)를 생성하고 언어 상태를 동기화하는 핵심 초기화 로직을 담당합니다.
*   **`js/i18n.js`**: 다국어 지원(Internationalization) 기능을 전담합니다.

## ⚖️ 사용 가이드라인 (Developer Notes)

**⚠️ 개발 시 주의사항**
1. **모듈 격리 준수**: 특정 기능을 수정할 때는 해당 기능 모듈 내부 파일에만 변경 사항을 한정해야 합니다.
2. **교차 관심사 고려**: 전역 상태나 UI 관련 변경은 반드시 `js/components.js`와 `js/i18n.js`를 통해 처리해야 합니다.
3. **도구 사용 제한**: 특별한 빌드 도구(예: WebPack 설정)가 제공되지 않는 한, 일반적인 프론트엔드 빌드 도구는 실행하지 마십시오.
